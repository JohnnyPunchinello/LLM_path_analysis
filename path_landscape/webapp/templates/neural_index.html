Neural-circuit analysis

A 4-agent pipeline that turns an emergent neural phenomenon into a path representation of the underlying circuit.

  1. 1 Research paper

    Identify a foundational paper about the circuit responsible.

  2. 2 Neural system

    Brain regions, cell types, and connectivity motifs.

  3. 3 Network

    Directed graph with input side, output side, feedback loops, and multiscale structure.

  4. 4 Path representation

    Unroll feedback loops in time; enumerate input → output paths; identify the system's time scale and the longer paths carrying feedback.
