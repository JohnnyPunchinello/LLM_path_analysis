The Shape of Emergence

Describe an emergent neural (or LLM) phenomenon and a 5-agent pipeline will identify the responsible circuit, map its input → output paths, cluster them into similarity modes, and classify the emergence using the path-landscape framework.

  1. 1 Research paper

    Identify a foundational peer-reviewed paper about the responsible circuit (biological or LLM/transformer).

  2. 2 Neural system

    Name the brain regions or computational modules, cell types / attention heads, and key connectivity motifs.

  3. 3 Network + schematic

    Build a directed graph (input side, output side, feedback arcs, multiscale groupings) and render a paper-sourced circuit schematic.

  4. 4 Path representation

    Unroll feedback in time; enumerate input → output paths; cluster routes into similarity modes (the path landscape).

  5. 5 Landscape interpretation

    Identify the emergence type, dominant structural features, and classify which of the 4 primitives operate: Path Activation, Path Suppression, Mode Merge, Mode Split.
